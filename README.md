# Task Tracker — Full Stack Mini Project

A simple task-management application built with Node.js, Express, HTML, CSS and vanilla JavaScript.

## Features
- View tasks
- Add a task
- Mark a task complete/incomplete
- Delete a task
- REST API with GET, POST, PATCH and DELETE endpoints
- Basic input validation
- Responsive UI

## Tech Stack
- Node.js
- Express.js
- HTML5
- CSS3
- JavaScript
- REST API

## Run locally

1. Install Node.js.
2. Open this project folder in a terminal.
3. Run:

```bash
npm install
npm start
```

4. Open `http://localhost:3000`.

## API endpoints

- `GET /api/tasks`
- `POST /api/tasks`
- `PATCH /api/tasks/:id`
- `DELETE /api/tasks/:id`

## Notes

Tasks are stored in memory for this demonstration, so they reset when the server restarts.
